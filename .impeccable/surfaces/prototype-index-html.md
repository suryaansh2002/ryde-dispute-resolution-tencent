# Surface: RydeResolve interactive prototype (prototype/index.html)

Scope: clickable HTML prototype, sign-off before the React rebuild. It has five spaces: Overview (Persuade) and four Operate apps. The Rider and Driver apps sit in phone frames; the Support console and the AI trace view are desktop. Real data snapshot from the Neon DB (9 cases, queue, golden run). Primary audience is hackathon judges, via recorded video, live presentation and self-exploration.

## Direction contract
THESIS: The calm of an Apple product page, applied to a courtroom. Each role sees its own polished app, and the AI's hearing is the one thing allowed to feel alive. It refuses dark dashboards, card grids, and gradient AI glow.
OWN-WORLD:
- Grounds: apple-grey #f5f5f7 and white.
- Ink: #1d1d1f.
- Primary actions: near-black pills.
- Blue: only for links and focus.
- Parties: violet for the rider, teal for the driver.
- Status: green, amber or red, always with a label.
- Type: SF Pro via the system stack, Geist as fallback, Geist Mono for evidence IDs.
- Shape: large radii on phone surfaces, hairline dividers, no nested cards.
STORY: A judge sees a rider file a dispute in a real-feeling app and the driver answer it. They watch two advocates argue from the same evidence and a judge rule with citations they can open. Plain-code gates send risky cases to a person, the support console handles those, and 22/22 shows it works.
FIRST VIEWPORT: Overview: a huge headline, left. Right: an iPhone showing the rider's outcome screen, beside a slim live trace column. A primary "Try a dispute" pill. Apps: the phone is centred on grey with a narration column.
FORM: user-pinned (Apple calm). No concept-seed run; the direction is pinned by the user on 2026-10-13. Signature move: the citation chip, which previews evidence on hover and opens it on click; plus the replayable hearing.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
